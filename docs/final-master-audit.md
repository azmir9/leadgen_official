## Remaining environment checks

- Report integration requires `TEST_MONGODB_URI` to point to a disposable local replica set with a `leadgen-test-<suffix>` database and `LEADGEN_CONFIRM_DISPOSABLE_TEST_DB=true`; the platform integration suite additionally requires `RUN_PLATFORM_INTEGRATION_TESTS=true`. Both suites reject non-loopback hosts, database-name overrides, and URI proxy settings. Do not run the platform suite unless the database is freshly disposable: it invokes the Bootstrap handler and initializes indexes inside that test database.
- After configuring only that disposable target, run `npx.cmd vitest run tests/report-isolation.integration.test.ts`. The platform workflow suite must be run separately and explicitly; it is not part of the safe default test command.
- A safe build check needs a build environment whose database target is verified and disposable or a build path that does not reach the configured database.
- Browser verification needs an available browser and browser test runner. Neither was present in the inspected project environment.
